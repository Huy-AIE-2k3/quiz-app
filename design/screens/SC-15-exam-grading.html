CÂU 15 (4.0 ĐIỂM) - ĐỀ BÀI:

Trong không gian Oxyz, cho hình chóp tứ giác đều S.ABCD có đáy ABCD là hình vuông cạnh 2a, chiều cao SO = a√2. Thiết lập phương trình các mặt phẳng bên, tính thể tích vật thể giới hạn bởi mặt cầu ngoại tiếp và viết thuật toán C++17 xấp xỉ tích phân thể tích bằng phương pháp Simpson với sai số ε ≤ 10⁻⁴.

Lời giải Ý a): Thiết lập hệ trục Oxy & Phương trình mặt bên [Học sinh làm tốt]

Chọn hệ trục toạ độ Oxyz với gốc O trùng với tâm mặt đáy ABCD. Khi đó:

A(-a, -a, 0), B(a, -a, 0), C(a, a, 0), D(-a, a, 0)
Đỉnh S(0, 0, a√2).
Véctơ SB = (a, -a, -a√2), SC = (a, a, -a√2).
Véctơ pháp tuyến [SB, SC] = (2a²√2, 0, 2a²) = 2a²(√2, 0, 1).
Phương trình mặt phẳng (SBC): √2(x - a) + 0(y - a) + 1(z - 0) = 0 ⇒ √2·x + z - a√2 = 0.

Sơ đồ toạ độ Oxyz & Mặt phẳng cắt (Scan SVG):

Hình vẽ thể hiện trục thẳng đứng Oz hướng từ tâm O lên S(0,0,a√2). Các góc toạ độ chân đáy vuông góc chuẩn xác theo hệ thức vector bàn tay phải.

Lời giải Ý b): Tính tích phân giới hạn & Thể tích V ⚠ Chú ý: Dấu đổi biến t bị nhầm

Thiết lập công thức tích phân phân lớp thể tích tròn xoay:

V = ∫₀^(a√2) S(z) dz = ∫₀^(a√2) [ 2(a - z/√2) ]² dz
Đặt t = a - z/√2 ⇒ dt = -1/√2 dz ⇒ dz = -√2 dt.
Đổi cận: z = 0 ⇒ t = a; z = a√2 ⇒ t = 0.
V = 4 ∫ₐ⁰ t² (-√2 dt) = 4√2 ∫₀ᵃ t² dt = 4√2 [ t³/3 ]₀ᵃ = (4a³√2) / 3.

#include <iostream>
#include <cmath>
#include <iomanip>
// Hàm tính diện tích thiết diện S(z) tại độ cao z
double crossSectionArea(double z, double a) {
double side = 2.0 * (a - z / std::sqrt(2.0));
return side * side;
}

double simpsonIntegrate(double a, int n) {
double h = (a * std::sqrt(2.0)) / n;
double total = crossSectionArea(0.0, a) + crossSectionArea(a * std::sqrt(2.0), a);
for (int i = 1; i < n; i++) {
double z = i * h;
if (i % 2 == 0) total += 2.0 * crossSectionArea(z, a);
else total += 4.0 * crossSectionArea(z, a);
}
return (h / 3.0) * total;
}

int main() {
double a = 1.0;
std::cout << std::fixed << std::setprecision(4) << simpsonIntegrate(a, 1000) << std::endl;
return 0;
}
